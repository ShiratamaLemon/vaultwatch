## 機能詳細

### 1. ウォレット接続

#### 概要
RainbowKitを使用したウォレット接続機能。

#### ユーザーストーリー
- ユーザーとして、MetaMaskやWalletConnectでログインしたい
- ユーザーとして、接続状態とアドレスを確認したい
- ユーザーとして、いつでもログアウトしたい

#### 機能要件

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| AUTH-01 | MetaMask接続 | 必須 |
| AUTH-02 | WalletConnect接続 | 必須 |
| AUTH-03 | Coinbase Wallet接続 | 任意 |
| AUTH-04 | 接続状態の永続化 | 必須 |
| AUTH-05 | ログアウト機能 | 必須 |
| AUTH-06 | アドレス表示（短縮形） | 必須 |
| AUTH-07 | ENS名表示 | 任意 |

#### UI仕様

**ヘッダー（未接続時）**
```
[Connect Wallet] ボタンを表示
クリック → RainbowKit モーダル表示
```

**ヘッダー（接続時）**
```
[0x1234...5678 ▼] アドレス表示
クリック → ドロップダウン（ダッシュボード、ログアウト）
```

### 2. プロジェクト登録

#### 概要
新規プロジェクトをDataHavenに登録する機能。

#### ユーザーストーリー
- プロジェクトオーナーとして、プロジェクト情報を登録したい
- プロジェクトオーナーとして、登録内容が改ざん不可能であることを確認したい

#### 機能要件

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| REG-01 | プロジェクト名入力 | 必須 |
| REG-02 | 概要入力（Markdown対応） | 必須 |
| REG-03 | カテゴリ選択 | 必須 |
| REG-04 | 公式URL入力 | 必須 |
| REG-05 | SNSリンク入力 | 任意 |
| REG-06 | ロゴアップロード | 任意 |
| REG-07 | 入力バリデーション | 必須 |
| REG-08 | DataHavenへの保存 | 必須 |
| REG-09 | トランザクション署名 | 必須 |
| REG-10 | 登録完了通知 | 必須 |

#### 画面遷移

```
/register
  │
  ├── [1] 基本情報入力
  │   └── プロジェクト名、概要、カテゴリ
  │
  ├── [2] リンク情報入力
  │   └── Website、Twitter、Discord、GitHub
  │
  ├── [3] 確認画面
  │   └── 入力内容の確認
  │
  ├── [4] 署名・送信
  │   └── ウォレット署名 → DataHaven保存
  │
  └── [5] 完了画面
      └── 成功メッセージ、プロジェクトページへのリンク
```

#### フォームフィールド

| フィールド | 種類 | 必須 | バリデーション |
|-----------|------|------|---------------|
| name | テキスト | ○ | 3-100文字 |
| description | テキストエリア | ○ | 10-500文字 |
| category | セレクト | ○ | 定義済み値 |
| website | URL | ○ | 有効なURL |
| twitter | URL | - | Twitter URL形式 |
| discord | URL | - | Discord URL形式 |
| github | URL | - | GitHub URL形式 |
| logo | ファイル | - | PNG/JPG, 1MB以下 |

#### ユーザーストーリー

#### 機能要件

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| COMMIT-01 | タイトル入力 | 必須 |
| COMMIT-02 | 詳細説明入力 | 必須 |
| COMMIT-03 | タイプ選択 | 必須 |
| COMMIT-04 | 目標日設定 | 任意 |
| COMMIT-05 | 証拠URL入力 | 任意 |
| COMMIT-06 | DataHavenへの保存 | 必須 |
| COMMIT-07 | トランザクション署名 | 必須 |

#### フォームフィールド

| フィールド | 種類 | 必須 | バリデーション |

### 6. データ検証機能

#### 概要
DataHavenに保存されたデータのMerkle証明による検証機能。

#### ユーザーストーリー
- ユーザーとして、表示されているデータが改ざんされていないことを確認したい
- ユーザーとして、検証の仕組みを理解したい

#### 機能要件

| 要件ID | 要件 | 優先度 |
|--------|------|--------|
| VERIFY-01 | 自動検証（データ取得時） | 必須 |
| VERIFY-02 | 検証ステータス表示 | 必須 |
| VERIFY-03 | Merkleルート表示 | 必須 |
| VERIFY-04 | 検証失敗時の警告 | 必須 |
| VERIFY-05 | 手動再検証ボタン | 任意 |
| VERIFY-06 | 検証詳細モーダル | 任意 |

#### 検証ステータス

| ステータス | アイコン | 説明 |
|-----------|---------|------|
| Verified | ✅ | Merkle証明検証成功 |
| Pending | ⏳ | 検証中 |
| Failed | ❌ | 検証失敗（改ざんの可能性） |
| Unknown | ❓ | 検証不能（オフライン等） |
